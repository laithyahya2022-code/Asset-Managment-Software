# Interactive demo

`itam-demo.html` is a **self-contained, interactive** preview of ITAM — a single
HTML file that runs entirely in the browser and saves to `localStorage` (no
server needed). It mirrors the real app's screens and lets you click around,
add/edit records, filter, print labels, etc.

This is **not** a screenshot tour — every button works.

## Use it
- **Open locally:** just double-click `itam-demo.html`.
- **Share a link:** publish it as an Artifact (in Claude Code, ask:
  *"Publish demo/itam-demo.html as an interactive artifact"*), which gives a
  shareable `claude.ai/code/artifact/...` link.

Because it's a browser-only preview, data is per-device and not shared — the
real shared system is `ITAM.exe` running on the server.
